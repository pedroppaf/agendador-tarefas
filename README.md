

# Serviço de Agendamento / Tarefas

Microsserviço backend desenvolvido com **Java** e **Spring Boot** responsável pelo gerenciamento de tarefas e agendamentos dentro de uma arquitetura baseada em microsserviços.

Este serviço concentra as regras de negócio relacionadas à criação, atualização, consulta e organização de tarefas/agendamentos no sistema.

Este serviço faz parte de uma solução maior em microsserviços, sendo responsável pelo domínio principal de tarefas/agendamentos e pela lógica central do sistema.

---

## Objetivo do serviço

Este microsserviço foi desenvolvido para praticar:

- gerenciamento de tarefas e agendamentos
- separação de regras de negócio em serviço independente
- persistência de dados
- organização em arquitetura distribuída
- construção de APIs REST com Spring Boot

---

## Responsabilidades

- criação de tarefas/agendamentos
- listagem e gerenciamento de registros
- persistência de dados
- integração com outros serviços da arquitetura
- aplicação de regras de negócio do domínio

---

## Tecnologias utilizadas

- **Java**
